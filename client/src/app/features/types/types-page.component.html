1. Metadata Fields

Custom structured attributes stored on the note. You define the field key, its data type (Text, Number, Boolean, or List), and whether it is required.

2. Body Section Templates

Markdown heading outlines (e.g. ## Summary, ## Action Items). When creating a note, these headings are automatically pre-populated. Validation ensures:

  • Required: Headings must be present.
  • Order: Headings must follow the defined sequence.
  • Repeatability: Non-repeatable headings cannot be duplicated.
update

3. Versions & Migrations

Types have version numbers (v1, v2). Modifying a Type creates a new version. Existing notes remain on their previous version until you inspect and approve a migration, ensuring your notes never break unexpectedly.
